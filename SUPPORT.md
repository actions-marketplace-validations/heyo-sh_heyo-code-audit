# Getting help

- Use [GitHub Discussions](https://github.com/heyo-sh/heyo-code-audit/discussions)
  for questions, workflow integration help, and early ideas.
- Use an issue template for reproducible bugs and well-defined feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before posting, check the README, existing discussions, and existing issues.
Never post API keys, OAuth tokens, AWS credentials, GitHub tokens, private
repository URLs, diffs, or customer data.
